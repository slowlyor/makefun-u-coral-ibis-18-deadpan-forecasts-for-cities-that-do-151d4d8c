A single deadpan one-line weather forecast for Bumbershoot Falls, a city that does not exist: a high of 58, light rain falling upward, a 12 mph north wind, and a 70% chance of brief confetti by 4 p.m., delivered in the flat, confident tone of a TV meteorologist. The program is deterministic, uses only the Node.js standard library, and writes the forecast to `/output/entry.txt`.

## Run it

```sh
node --experimental-strip-types main.ts
```

## Output

`/output/entry.txt` contains the single forecast line (150 characters).
